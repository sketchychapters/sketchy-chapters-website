Program Overview:

AutoCAD is the computer-aided design software relied upon by engineers, architects, and construction professionals to create precise 2D and 3D drawings. It allows you to draw, document, and design geometric shapes with high flexibility, while automating repetitive tasks such as counting, adding blocks, and creating data tables efficiently.

Curriculum Objectives:

The primary goal of this course is to teach users the essential commands and tools for professional drawing, design, and engineering planning using AutoCAD. Upon completion, participants will be able to:

  • Employ AutoCAD in daily engineering workflows.
  • Navigate the interface fluently using various display tools.
  • Master sound engineering drawing concepts and techniques.
  • Create multiple designs using editing tools and layers.
  • Output plates, add text/notes, and print to precise scales.
  • Use constraints to control custom designs.
