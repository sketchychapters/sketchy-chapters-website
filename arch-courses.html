AutoCAD 2D/3D

Sessions 9 Sessions (3 Wks)
Price 149$ 45% Off (Original: 298$)
Start Date 17/08

Program Overview:

AutoCAD is the computer-aided design software relied upon by engineers, architects, and construction professionals to create precise 2D and 3D drawings. It allows you to draw, document, and design geometric shapes with high flexibility, while automating repetitive tasks like counting, adding blocks, and generating data schedules efficiently.

Curriculum Objectives:

The primary goal of this course is to teach users the commands and tools needed for professional drawing, design, and engineering planning using AutoCAD. Upon completion, participants will be able to:

  • Integrate AutoCAD into daily engineering workflows.
  • Navigate fluently within the interface using various display tools.
  • Master sound engineering drawing concepts and techniques.
  • Create multiple designs using editing tools and Layers.
  • Output sheets, add text/notes, and print to precise scales.
  • Use Constraints to control custom designs.

Revit Part 1

Sessions 9 Sessions (3 Wks)
Price 149$ 45% Off (Original: 298$)
Start Date 17/08

Program Overview:

Use Autodesk Revit for Building Information Modeling (BIM) to enhance efficiency and accuracy across the entire project lifecycle; from conceptual design, visualization, and analysis, to execution and construction. Start with high-precision 3D modeling and let the software automatically update floor plans, elevations, and sections as the model evolves.

Curriculum Syllabus:

  • Introduction to BIM and Autodesk Revit: Interface walkthrough, starting projects, basic view/draw/modify tools, setting up Levels and Grids, adding columns, and linking/importing AutoCAD files.
  • Architectural Design Development: Modeling and modifying walls, handling doors, windows, curtain walls, managing floor plans, elevations, sections, and adding components.
  • Advanced Architectural Elements: Modeling floors, openings, sloped floors, suspended ceilings, fixtures, and Roofs.
  • Circulation & Documentation: Creating and modifying stairs, railings, ramps, working with materials, and basic output/rendering settings.
